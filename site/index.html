KOVA

One process stores the documents, answers SQL, and searches text.

Getting started Leave your email

Connect

Any MongoDB driver. Host 127.0.0.1, port 27018.

Run

Install the Linux build, then run kova. Data stays in data/.

Open by default

Security is off until you enable it. Then the client sends both a user and a password.

Getting startedInstall the Linux build, start the listener, write a document, read it after a restart. How data is storedDatabases, collections, pages, and the log that makes a write durable. DocumentsInsert, update, delete, and the commands a driver sends. SQLOne SELECT over the same collections, from a shell or from ODBC. Backupkovadump writes a file and reads SQL and MongoDB dumps back in. Copies and shardsA replica set copies the data. Shards split it across processes.
