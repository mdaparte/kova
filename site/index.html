KOVA

One process stores the documents, answers SQL, and searches text. Open source, under the Apache License 2.0.

Getting started Leave your email

Search the words

Find a word in what you stored. A typo still matches. The same search can count the results by a group, such as job, or by a band of numbers, such as salary.

Add a row, then query it

Create the collection, insert a document, change it, and add an index on a field you look up. A SQL query reads those same rows.

Take a copy

Save the database to a file and load that file back. The file holds the documents, the indexes, and the views.
