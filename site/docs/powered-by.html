Kova is a Rust program. Each picture is one library version 0.1.0 links, and the job that library does.

The crates.io package name is kovadb. The library name inside that package is kova. How to depend on it is on Getting started. Version 0.1.0 is published from GitHub Actions when a merge into main changes the crate sources. It is not on crates.io yet.

What the server stands on

Rust Edition 2021 The language. The server, kovadump, and libkova.so are one crate. Tokio 1 The async runtime. The listener accepts connections here. Partition workers are ordinary threads. bson 2 Document encoding on the wire and inside a page. Apache DataFusion 45 SQL. A statement and the ODBC driver run here, over the documents already stored. Tantivy 0.22 The text index. BM25 ranking, a fuzzy edit distance, and facets. OpenRaft 0.9 Replica sets. Voters copy the primary's log and elect a new primary. zstd 0.13 Compression of page bodies. The log stays uncompressed. Argon2 0.5 Password hashes, once [security] is enabled. AES-GCM 0.10 Optional encryption of page files and the log, after compression.

Also linked

Serde 1 Config, the index snapshot, and the dump records. toml 0.8 Reading kova.toml. serde_json 1 JSON where the payload is not BSON. The planned feed record is JSON. crossbeam-channel 0.5 The queue from the listener to a partition worker. regex 1 Regular expressions in a filter. bytes 1 Buffers on the wire. unixODBC The host's The driver manager on Linux. libkova.so loads libodbcinst.so.2 when a SQL client connects.

How a SQL client loads the driver is on the ODBC page.

Apache Iggy

Apache Iggy Planned Not linked in 0.1.0 The neighbor for the feed. Kova 0.1.0 does not link an Iggy crate and does not start an Iggy process. When the feed lands, Kova publishes one JSON record after a committed write, and Iggy stores the stream.

The record shape is on the Feed page.
